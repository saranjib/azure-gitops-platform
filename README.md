# Azure GitOps platform
## Full GitOps Kubernetes Platform with Terraform, AKS, GitLab CI, Argo CD, Prometheus, Grafana & Slack

A production-style DevOps and platform engineering project that provisions Azure Kubernetes Service infrastructure with Terraform, automates application builds and testing using GitLab CI, and continuously deploys applications to Kubernetes through Argo CD.

The platform also includes Prometheus and Grafana for observability, Alertmanager for notifications, and deployment metrics to measure delivery performance.
